# 🚨 Earthquake Tracker - Web & Legal Portal

Welcome to the public web and documentation portal for **Earthquake Tracker**, a Flutter-based mobile application that provides real-time global seismic monitoring, custom proximity radius filtering, and map integrations.

---

## 🌐 Live Pages

* 🏠 **App Web Page:** https://GeorgeTak.github.io/earthquake-app-website/
* 🔒 **Privacy Policy:** https://GeorgeTak.github.io/earthquake-app-website/privacy-policy.html

---

## 📱 App Highlights

* **Real-Time Data:** Powered by the official [USGS Earthquake API](https://earthquake.usgs.gov/fdsnws/event/1/).
* **Privacy-First Design:** All location calculations happen locally on the user's device. No personal data or location coordinates are ever stored or shared.
* **Proximity Radius Filtering:** Easily set maximum distance and magnitude filters to see relevant earthquakes near you.
* **Interactive Maps:** Direct link integration with native maps to view precise seismic epicenter coordinates.

---

## 🔒 Privacy & Data Usage Summary

* **Location Access:** Used strictly on-device to compute distance between the user's position and earthquake epicenters.
* **Third-Party Services:** Integrates only with public geological data endpoints from the USGS.
* **Data Storage:** Zero database tracking, continuous location monitoring, or third-party ad network tracking.

For full details, read the complete [Privacy Policy](privacy-policy.html).
